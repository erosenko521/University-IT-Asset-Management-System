# University IT Asset Management System

**Система учёта IT-активов факультета математики и информационных технологий ВГУ им. П.М. Машерова**

Комплексное программно-техническое решение для автоматизации инвентаризации, контроля жизненного цикла и управления парком IT-оборудования университета. Проект разработан в рамках курсовой работы по дисциплине «Базы данных» и готов к практическому внедрению.

## 🚀 Особенности проекта

*   **Архитектура «База данных как ядро»:** Вся бизнес-логика (расчёт износа, правила замены, безопасное удаление) инкапсулирована на уровне СУБД Microsoft SQL Server через хранимые процедуры, триггеры и функции. Клиентское приложение выступает лишь тонким интерфейсом.
*   **Безопасность данных:** Отказ от рискованного `ON DELETE CASCADE` в пользу контролируемых процедур (`Delete_Asset_Safe`), обеспечивающих целостность связей при удалении активов.
*   **Проактивное планирование:** Автоматический расчёт возраста оборудования и формирование рекомендаций по замене на основе дифференцированных правил для разных типов устройств (серверы, ПК, принтеры).
*   **Информационная безопасность:** Встроенные механизмы выявления устаревших ОС и контроля лицензионной чистоты ПО через представления (`Outdated_OS_Assets`, `Software_License_Report`).
*   **Полный аудит:** Автоматическое фиксирование времени создания и изменения записей, а также истории технического обслуживания.

## 🛠 Технологический стек

*   **Backend / DB:** Microsoft SQL Server (T-SQL), SSMS.
*   **Frontend:** Java SE (Swing), JDBC.
*   **Инструменты:** Git.
